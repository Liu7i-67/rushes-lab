## 0. 构建安卓包(验收前置)

```bash
cd material-storage/app
export PUB_HOSTED_URL=https://pub.flutter-io.cn FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
export JAVA_HOME=E:/qbb/soft/java ANDROID_HOME=E:/qbb/soft/android_sdk
/e/qbb/soft/flutter/bin/flutter build apk --release \
  --dart-define=APP_BUILD_TIME="$(git log -1 --format='%cd' --date=format:'%Y-%m-%d %H:%M')"
# 产物 build/app/outputs/flutter-apk/app-release.apk(~61MB)
```

- **确认装的是新包**:项目页标题应显示「项目 · 最后编辑 <stamp> · <用户名>」,
  stamp=上述命令取的 git HEAD 提交时刻(终版 ae31cd9 = **2026-10-21 14:15**);
  看不到时间段的构建漏带了 dart-define,请重打。
- 最低支持 Android 10(API 29,安装门槛);iOS 侧待 Mac 同事按
  `ios-livp-app-build-handbook.md` 路线 A 出 TestFlight 后同清单补验。
- 手机需能访问:内网 `http://192.168.110.221`(工作室 WiFi)或公网
  `https://bucket.taoxiplan.com`(任意网络)。

## B1 · 基建(登录/会话/我的页)

前置:一个普通账号(如 dev 的测试账号);如有 `must_change_password=true` 的账号更佳。

1. **探活**:工作室 WiFi 冷启动 → 直达登录页(「我的」页应显示内网入口);
   切蜂窝网络重启 App → 应自动落到公网入口;飞行模式冷启动 → 登录页
   「服务不可达·重试」横幅,关飞行模式点重试恢复。
2. **登录/会话**:登录成功进四 tab 主界面;杀 App 重启 → 免登录直达;
   退出登录(我的→退出)→ 回登录页,重启仍停留登录页。
3. **强制改密**(如有该状态账号):登录后只能停在改密页(无返回),改完进主界面;
   「账号与安全」改密正常,旧密码错误有后端文案。
4. **我的页**:账号信息/账号与安全/诊断(日志推送)/当前服务入口(只读)/退出。

## B2 · 浏览与预览

前置:项目内有各类型素材(图片/视频/livp/heic/md/pdf/svg/大文件)。

1. **项目列表**:权限徽标(管理/上传/下载/查看/仅访客,多角色 +N)。
2. **文件夹**:树状缩进多级下钻;子夹有文件时徽标数字;敏感夹锁图标。
3. **宫格**:缩略图加载(无缩略图的类型显示色块);视频「视频」角标、
   livp「实况」角标;长按进入多选(打勾+「已选 n 项」)。
4. **预览**:点按素材 → 暗色画布+顶部 ‹n/N›+胶片条切张(边界即停)+
   底部元数据卡(文件名/大小/类型/时间/标签/备注)。
   - 视频:可播放/暂停/拖进度;Android 对 HEVC .mov 若起播失败应有「下载后打开」降级;
   - livp:显示静态图,「播放实况」播短片(循环静音),「查看照片」回静态图;
   - heic:1024px 缩略图;svg/avif/ico:无缩略图时色块;md/text:正文渲染;
     pdf:iOS 分享面板/Android 提示下载后打开。
5. **刷新**:上传/删除后列表自动更新(不整页转圈);下拉刷新有加载圈。

## B3 · 上传与传输

前置:目标文件夹对账号可上传;准备相册实况/普通图视频/文件(含 GB 级大文件)。

1. **统一上传**:宫格右上「⬆」→ 半屏面板两选(从相册/选择文件);多选后即入队,
   面板可关继续浏览;toast「已入队 x 个,跳过 y 个」(单个失败不阻断整批)。
2. **iOS 实况**:相册选实况照片自动打包 .livp 上传,上传后 web 端可见且缩略图正常。
3. **传输页**(tab3):进行中显示进度/百分比/可取消;失败可重试(从头传);
   已完成可移除;底部 tab「传输」格 badge=进行中数;宫格顶部迷你进度条。
4. **大文件**:GB 级视频上传不闪退不 OOM;上传中切到其他页不中断。
5. **取消**:传输页取消进行中任务 → 状态变已取消,不再占用并发位。

## B4 · 下载与双端落盘(重点)

前置:各类素材;Android 检查图库与 Download/浣花视界/ 目录;iOS 检查相册与文件 App。

1. **单资产下载**:预览页「下载」(无下载权的文件夹该钮禁用并给申请提示):
   - Android livp:**图库出现静态图+视频(实况恢复)且 Downloads/浣花视界/ 有
     .livp 原档(双落盘)**;toast 说明去处;
   - Android 图片/视频:入图库;Android pdf/其他:入 Downloads/浣花视界/;
   - iOS livp:存相册恢复实况;失败时弹「存储到文件」兜底;iOS 其他:分享面板存储。
2. **批量下载**:宫格多选 → 底部操作栏「下载」逐文件入队(>20 个有确认弹窗);
   传输页可见各任务进度。
3. **重名/失败**:同名再下载自动加序号不覆盖;断网下载失败任务可重试。
4. **空间不足**(可选):存满存储后下载 → 前置提示并中止,不半途写坏。

## B5 · 素材操作线

前置:需要多选权限的文件夹;准备打标/前缀测试数据。

1. **分享**:恰好选中 1 个 → 「分享」可用(多选时置灰);有效期四档(1h/24h/7d/30d);
   创建后自动复制链接(toast),可选浏览器打开落地页(落地页需登录态)。
2. **移动**:多选「移动」→ 仅选目标文件夹(项目固定),确认后列表更新;
   跨项目混选场景不可达(同批只能同项目)。
3. **删除**:多选「删除」→ 确认 → 列表移除;无权限时后端 403 文案正确。
4. **⋯ 菜单**:批量打标(merge/replace 可选,≤50 标签)/批量前缀(添加/移除)/
   申请权限(仅单选:访问=敏感夹/下载=需选有效期;理由必填 ≥4 字)。
5. **回收站**:文件夹 ⋯ → 回收站:软删列表/恢复成功回列表;
   入口按权限(普通夹管理/删除授权;敏感夹仅系统 admin)。
6. **详情打标**:预览页元数据卡「编辑」改标签与备注,保存后刷新生效。

## B6 · 文件夹与项目管理

前置:账号有 is_project_creator(或用系统 admin);艺人开通需 is_artist_account_creator。

1. **夹管理**(文件夹 ⋯ 菜单):新建子夹(敏感开关仅项目根有义)/重命名/移动
   (目标不含自身子树)/删除(空夹硬删有确认;非空 409 文案「请先删除其中所有文件」)。
2. **敏感夹邀请**:邀请(选人 viewer/downloader+有效期五档含永久)+撤销;
   **普通一级夹授权**:添加(选人/组+多 level 无有效期)+撤销;
   子夹与敏感夹无「授权管理」入口(契约如此)。
3. **新建项目**:名称/code/描述+项目管理员(默认自己)+bucket(高级折叠,默认 ms-dev)
   +权限模板(展开成行可增删改)+目录模板+艺人账号(登录名预检;**一次性密码仅显示
   一次**);无「可见性」字段;成功后项目列表刷新。
   - code 冲突 →「项目 code 已存在」;艺人登录名冲突 →「登录名已被占用」。
4. **成员管理**:项目行「成员」→ 列表/添加(用户/组×四角色)/移除/授权总览。
5. **已删除项目**:我的→回收站(项目)——**仅 is_project_deleter 可见**;恢复生效。

## B7 · 协作线(审批/通知/我的权限/搜索)

前置:两个账号(一个 admin,一个普通);普通账号发起过下载申请;admin 造一条通知。

1. **审批中心**(我的→审批中心):admin 默认进「待我审批」(badge=待审数),
   普通账号默认进「我发起的」(**badge 仅 admin 显示**);卡片(申请人/动作/对象/理由);
   通过/拒绝有确认(可填备注);决策后列表刷新;无权决策 403 文案。
2. **通知**:列表未读橙点;点未读 → 立即变已读+红点减一;「全部已读」;
   30s 轮询驱动我的 tab badge;点通知跳审批中心/项目(未知类型不跳不崩);
   进后台/登出停轮询,回前台立即刷新。
3. **我的权限**:项目角色+临时授权(到期倒计时变色:10% 红/30% 黄);
   数据源=项目角色+已批准申请。
4. **搜索**(tab2):输入防抖;结果=缩略图+命中高亮+归属+类型徽标;
   ≥50 结果有截断提示;点结果进预览(结果序列切张);清空即清列表。

## B8 · 管理后台(需系统 admin)

前置:系统 admin 账号(dev: evan;prod 账号见运维手册);另备一个仅
is_folder_template_manager 的账号验目录模板独立入口。

1. **入口**:我的→管理(仅 admin;持目录模板旗标的非 admin 仅见目录模板一个入口)。
2. **用户**:列表搜索分页;建用户带组(**一次性密码仅显示一次**);编辑(姓名/邮箱/
   启停);重置密码(一次性回显);解锁(仅锁定行出现)。
3. **组**:建/编(开关仅改动过的提交);成员加/移(**操作后抽屉驻留**可连续操作)。
4. **审计**:筛选(事件类型/项目/主体/日期)+分页;**CSV 导出**:Android 落
   Downloads/浣花视界/(iOS 分享面板),文件可打开且含表头(UTF-8 BOM)。
5. **权限模板**:建(主体行×角色,≤50)/编辑/删除;**应用默认**:多选项目批量,
   结果逐项目呈现(补写/跳过过期/失败)。
6. **目录模板**:建(路径非法前端拦)/编辑(**「不使用模板」可回退**)/删除。
7. **百度任务(管理)**:全量列表状态筛选/详情/文件明细;**文件级三操作仅任务
   归属者本人可用**(他人置灰+表头提示——后端暂无 admin 文件级端点,已知边界)。

## B9 · 百度用户侧+请求链接+维护横幅

前置:账号已绑百度网盘(未绑定则先走绑定);admin 账号;可制造跨项目同名目录数据。

1. **绑定**(如未验):我的→网盘备份→绑定:外开授权链接→浏览器授权→复制授权码
   →回 App 粘贴→成功(入口显示昵称);错误码/过期有明确文案。
2. **网盘浏览**:新建任务向导的网盘目录树:展开懒加载/文件行灰显/错误可重试。
3. **建任务**:选项目+承接夹(项目根或指定夹)+源目录 → 创建成功入列表;
   同名冲突场景:任务失败后详情内逐文件「随机后缀导入」/「覆盖导入」
   (处置手册三方案);向导本身无覆盖选项。
4. **任务管理**:列表(状态/进度/排队徽标)/取消(确认)/重试失败/删除;
   详情文件分页+三操作(non_retryable 置灰)。
5. **请求链接**:项目页菜单(项目 admin 可见)与文件夹 ⋯ 菜单(夹 admin 可见,
   **无权限者不显示该菜单项**);动作勾选(access 仅敏感夹)/有效期;创建即复制。
6. **维护横幅**:让运维在 dev 设 active banner(redis)→ App **未登录**也会弹
   不可关闭的维护提示;结束(active→false)→「升级完成」数秒自动关;
   维护期间网络错误不误判完成。
