# ms-mcp 镜像依赖版本约束(pip constraints)—— material-storage/mcp 独立闭包

# 用途:Dockerfile `pip install -c constraints.txt .`。依赖声明在 pyproject.toml,

#   api 的 egg-info / uv.lock / constraints 都管不到本目录(方案 D14)。
# ★ dev 组(pytest / ruff)不进镜像,不受本文件约束。
#
# 来源:2026-10-31 在干净 Python 3.12 venv 里
#   `uv pip install "mcp==1.30.0" "httpx>=0.27" "uvicorn>=0.31"` 后 `uv pip freeze`
#   (pywin32 是 mcp 的 Windows-only 依赖,Linux 镜像不会安装,故不列)。
# 升级流程:改 pyproject 的 mcp pin → 干净 venv 重装 → 重生成本文件 → build →
#   本地 `uv run pytest` → dev 容器 initialize 冒烟 → prod。
