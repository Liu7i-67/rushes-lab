# 移动端 UX 优化批(P1-P10)真机验收清单

> 对应需求:`docs/qdev/2026-10-21-mobile-ux-polish.md`(测试功能点 1-11)。
> 本清单收口**无法在 PC 单测环境自动化**的平台行为:系统权限弹窗、通知栏、
> 应用跳转、真机手势(捏合/慢速拖动)、dart-define 构建注入等。
> 自动化覆盖见各 `test/**/*_test.dart`(P1/P3/P7 为 target-behavior 锁,
> 实现落地前对应断言会红,落地后须全绿)。
> 每条:【前置条件】→【步骤】→【预期】。执行人/日期/结果建议在勾选框后补记。

---

## P1 预览页底部操作栏避开虚拟导航栏

### P1-1 三钮完整可见可点
- 前置:带虚拟导航栏(三键/手势条)的 Android 真机;任一图片/视频进入预览页。
- 步骤:观察预览页底部「下载 / 分享 / 申请权限」三钮;分别点按。
- 预期:三钮完整可见、均可点中(无被虚拟按键压住的半截);导航栏区域背景为
  darkSurface 深色,不露出画布底色;无虚拟导航栏的设备(如 iOS)视觉与改动前一致。

## P2 相册选择:直通系统权限 + 中文引导

### P2-1 首次安装直通系统权限弹窗
- 前置:卸载重装(权限未决定);Android 13+ 真机。
- 步骤:登录 → 进入项目文件夹宫格 → 点上传 → 「从相册选择」。
- 预期:直接弹出系统相册权限弹窗(系统样式);选择「允许全部/仅允许访问选中的照片」后
  直接进入选图界面,全程无英文 PermissionGuide 页面。

### P2-2 picker 内置界面全中文
- 前置:相册权限已授权。
- 步骤:进选图界面,检查顶部「确认/预览」、权限受限提示、空目录等内置文案。
- 预期:选图器全部界面为中文(含「无法访问所有资源」「前往系统设置」等权限引导覆盖层)。

### P2-3 拒绝过的中文引导 +「去设置」跳转
- 前置:系统设置里已拒绝相册权限(或「仅限选中」后取消全部)。
- 步骤:点上传 → 「从相册选择」。
- 预期:弹出中文对话框「需要相册访问权限」,正文说明用途;点「去设置」→
  跳到系统应用详情页(package:com.rushes.lab.tx);授权后返回 App 再点上传可直接进选图;
  点「取消」→ 不进入选图、无异常 toast。

### P2-4 iOS 侧中文引导(有条件则验)
- 前置:iOS 真机,相册权限为拒绝/受限。
- 步骤:同上入口。
- 预期:中文引导对话框,按钮为「重新尝试」+「取消」;「重新尝试」重新发起系统授权请求。

## P3 预览页横滑切换 + 缩放联动

### P3-1 放大态拖动为平移图片,不切页
- 前置:预览页打开任一图片。
- 步骤:双指捏合放大到 2x+ → 单指左右拖动。
- 预期:拖动为平移查看图片局部,顶部计数不变(不触发切页)。

### P3-2 捏合还原后恢复横滑切页
- 前置:接 P3-1 放大态。
- 步骤:双指捏合缩回 scale≈1 → 单指快滑(接近甩动速度)。
- 预期:恢复左滑下一张/右滑上一张;慢速单指拖动不切页(快滑阈值,防误触)。

### P3-3 视频/livp/文档类横滑
- 前置:混排素材(视频、livp、md/text)进入预览。
- 步骤:在视频播放页/实况照片/文档页分别左滑右滑。
- 预期:同样可横滑切张,边界即停;视频切走后停止播放(资源释放)。

### P3-4 胶片条点选切页(回归)
- 步骤:点底部胶片条任一缩略图。
- 预期:立即切到该张,计数/文件名/胶片条高亮同步。

## P4 项目内文件夹页顶部显示项目名

### P4-1 长项目名 + 系统大字体不溢出
- 前置:真机系统字体调大(最大档);项目名较长(>20 字)。
- 步骤:进入该项目文件夹页。
- 预期:顶部标题为项目名,自动缩小显示,无右溢出省略异常、无黄黑条纹溢出警告。

## P5 目录树实心深色图标(对齐 web)

### P5-1 与 web 端语义对照
- 前置:同一账号同项目,web 端与 App 端各开一份文件夹树。
- 步骤:对照每个文件夹图标形态。
- 预期:web 上「实心=含文件」的夹,App 上同样是实心深色(#1A1A1A);
  空夹两端同为橙色空心;「N 项」badge 数值与 web 一致。

## P6 项目页标题清理 + stamp 迁移

### P6-1 打包注入 stamp 后我的页显示构建行
- 前置:用正式命令打包(`--dart-define=APP_BUILD_TIME=...`,见需求文档附)安装。
- 步骤:进「我的」页看用户信息区下方;再回项目页看标题。
- 预期:我的页显示「构建 YYYY-MM-DD HH:mm」小字(与本批 git HEAD 时间一致);
  项目页标题恒「项目」,无日期、无用户名、无 bug 图标;旧包(本批之前)项目页标题
  带「最后编辑」段可继续用于区分新旧。

### P6-2 日志推送入口保留(回归)
- 步骤:登录页右上角、「我的」页诊断区分别点日志推送入口。
- 预期:两处均可打开「推送日志到企业微信」对话框(P10 身份行见 P10-1)。

## P7 无下载权限预览回退缩略图

### P7-1 仅查看权限用户打开图片
- 前置:仅 viewer(无 download)权限账号;打开一张已生成缩略图的图片。
- 步骤:进入预览页。
- 预期:大图区显示缩略图放大(清晰度略低),页内出现小字提示
  「原图不可用(无下载权限或加载失败),当前为缩略图预览」;不再出现「预览加载失败」卡。

### P7-2 有下载权限用户原图不变(回归)
- 前置:有 download 权限账号打开同一图片。
- 预期:仍加载原图,无降级提示。

### P7-3 无缩略图资产失败卡不变(回归)
- 前置:worker 未生成缩略图的资产(或生成失败的)。
- 预期:仍显示「预览加载失败」失败卡与「下载后打开」引导,无降级提示。

## P8 上传/下载完成系统级通知

> 实现侧 `services/notifier.dart` 落盘后可补 mock 桩单测(后台/前台闸门、聚合、
> 权限幂等在单测锁一层);通道行为本身按下面真机项验收。

### P8-1 Android 13+ 通知权限按需请求(幂等)
- 前置:Android 13+ 真机,App 通知权限未决定;卸载重装保证首次。
- 步骤:登录后先不开传任何任务,确认启动过程无通知弹窗;随后入队一个上传或下载任务。
- 预期:入队时弹一次系统通知权限弹窗;拒绝后再次入队**不再弹**(幂等,不骚扰)。

### P8-2 后台/锁屏完成 → 系统通知
- 前置:通知权限已授权。
- 步骤:入队上传(或下载)→ 立即切到桌面或锁屏 → 等任务完成。
- 预期:系统通知栏出现结果通知,标题「上传完成/下载完成/上传失败/下载失败」+
  文件名(或保存结果摘要);点开通知回到 App,传输页可见该任务终态。

### P8-3 前台完成不打扰(回归)
- 步骤:留在 App 内等任务完成。
- 预期:无系统通知;应用内表现与现状一致(下载完成 SnackBar 摘要、上传迷你条进度)。

### P8-4 批量完成聚合一条
- 步骤:一次选 5+ 张图片入队上传 → 切后台等全部完成。
- 预期:只收**一条**汇总通知(如「上传完成:5 个文件」或「3 成功 · 2 失败」),不逐文件轰炸。

## P9 密码框明文切换(真机回归)

### P9-1 真机键盘弹出下眼睛可点、切态可用
- 前置:真机(软键盘弹出压缩布局)。
- 步骤:登录页输入密码 → 点眼睛 → 再点;改密页三框同法;随后完成一次登录。
- 预期:键盘弹出时眼睛按钮不与键盘/建议条重叠、可点;明文可见已输入内容,
  切换不丢内容不丢焦点;登录/改密流程照常成功。

## P10 企微日志推送携带用户名

### P10-1 登录态推送:先身份消息后文件
- 前置:已登录;企微群机器人可收消息。
- 步骤:「我的」页(或登录页)→ 日志推送 → 点「推送」。
- 预期:企微群**先**收到一条 text:「【移动端日志】用户 <name>(uid <id>)·
  yyyy-MM-dd HH:mm」,**随后**收到日志文件;对话框显示「当前用户:<name>」;
  推送成功后本地日志清空。

### P10-2 未登录推送:只收文件
- 前置:退出登录在登录页。
- 步骤:右上角日志推送 → 推送。
- 预期:群里只收到日志文件,无身份 text 消息。
